
## Key

A key is required. Add the provider under **Settings → Providers**, paste the
key, then use **Fetch models**.

Keys are stored in IndexedDB in your browser. You can encrypt them under a
passphrase from **Settings → Privacy & data → Encrypt API keys**.
