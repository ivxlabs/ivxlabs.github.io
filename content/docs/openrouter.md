OpenRouter reaches many hosted models through one API. It is seeded in
ivx/ai Chat, so it is already listed under **Settings → Providers**.

## Base URL

```
https://openrouter.ai/api/v1
```

## Key

Get one at [openrouter.ai/keys](https://openrouter.ai/keys). Paste it into the
provider, then use **Fetch models**.

Keys are stored in IndexedDB in your browser. You can encrypt them under a
passphrase from **Settings → Privacy & data → Encrypt API keys**.
