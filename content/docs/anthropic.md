## Base URL

```
https://api.anthropic.com
```

## Key

A key is required. Add the provider under **Settings → Providers**, paste the
key, then use **Fetch models**.

Anthropic needs an opt-in header for direct browser use, which the app sends
for you.

A key used from a browser is visible to anyone using that browser.
